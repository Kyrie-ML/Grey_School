# Grey School Academy

The production frontend for Grey School Academy — a responsive, editorial junior-school website built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide.

## Local development

```bash
npm ci
npm run dev
```

On the original Windows workstation, `npm run dev` automatically mirrors generated runtime files to `D:\GreySchoolRuntime` because the C: drive has limited free space.

## Deployment

Pushes to `main` are built as a static Next.js export and deployed through GitHub Actions to GitHub Pages.

Production URL: <https://kyrie-ml.github.io/Grey_School/>
